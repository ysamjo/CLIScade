## harness-router-gui: Chrome aus der Haupt-GUI entfernt

Auftrag: Screenshot der Top-Leiste („Aktives Projekt / + Neuer Task / Usage /
Verbunden") — „das kann alles von der haupt gui raus". Zweiter Screenshot zeigte
Starten/Beenden im Interaktiven Terminal.

Entscheidungen (Rückfrage an Andreas, seine Antworten in Klammern):

- Top-Leiste komplett entfernt, inkl. „+ Neuer Task" — der Task-Start pro Projekt
  existiert weiter als „＋" im Projekt-Header des Sidebar-Baums.
- Verbindungs-Status bleibt als **reiner Punkt** in der Sidebar-Fußzeile
  (`Kleiner Punkt bleibt`). Text steht jetzt im `title`; `setConnectionState()`
  setzt kein `textContent` mehr. Roter Punkt + Pulsanimation = getrennt.
- Starten/Beenden: Andreas' Erwartung war „das startet doch, wenn ich auf
  Interaktives Terminal gehe". Also: **Auto-Start** statt Start-Knopf. „Beenden"
  ist in den Terminal-Header gewandert (dort, wo schon „Leeren" sitzt).
  Neustart nach manuellem Beenden: Modus-Knopf erneut klicken.

Technisch:

- Auto-Start-Logik in `app.js`: `maybeAutoStartInteractive()` +
  `state.interactiveAutoStartArmed`. Scharf gestellt beim Betreten des Modus,
  entwaffnet nach dem ersten Startversuch — sonst würde ein Health-Refresh das
  Terminal wieder hochziehen, das man gerade beendet hat. Hooks: `ws.onopen`,
  Ende von `renderInteractiveCliSelect()`, `setStudioMode()`,
  `setupInteractiveTerminal()`.
- Entfernte DOM-IDs mussten aus dem `dom`-Objekt in `app.js` raus:
  `currentProjectName`, `currentProjectPath`, `newTaskTopBtn`, `topUsageBtn`,
  `topUsageBadge`, `interactiveStartBtn`, `interactiveStartLabel`. Ersatz für
  den Projektnamen: neue Funktion `activeProjectName()`.
- Toter Code mit raus: `shortTokenCount()` (nur vom Top-Bar-Badge benutzt),
  der Usage-Badge-Block in `renderUsageUI()`.
- Mobile-Hamburger lag in der Top-Leiste → in `.studio-mode-switch` verschoben.
  **Dabei einen alten Bug gefunden:** `.btn-icon-mobile` stand global auf
  `display: none !important`, die Mobile-Regel nur auf `display: inline-flex` —
  der !important gewann, der Knopf war auf dem Handy nie sichtbar. Fix in der
  Media Query auf `display: inline-flex !important` (plus ID-Selektor).
- CSS aufgeräumt: `.top-bar`, `.active-project-badge`, `.top-bar-actions`,
  `.badge-*`, `.btn-outline-sm`, `.btn-usage-top*`, `.interactive-actions` raus.
